# Demo Assets

This folder contains demo materials for the Antarctic project.

## Contents

- `antarctic_demo.gif` - Animated GIF demonstration of the application

## Creating the Demo GIF

See the main project documentation for instructions on creating the demo GIF:
- `GUIA_GIF.md` - Spanish guide
- `tools/README_TOOLS.md` - English documentation

## Guidelines

- Keep GIF file size under 5MB
- Recommended dimensions: 800px width
- Duration: 10-15 seconds
- Show key features of the application
